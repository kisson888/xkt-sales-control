# 天河源筑销控表

单页 HTML 楼盘销控管理应用，支持楼栋配置、成交数据导入、多维度筛选、导出打印等功能。

## 功能特性

- **楼栋框架配置**：支持多楼栋、多单元、多房型、楼层范围自定义
- **拖拽排序**：楼栋卡片可拖拽排序，自动同步首页 Tab 顺序
- **成交数据导入**：支持 Excel/CSV/粘贴三种方式批量导入成交数据
- **多维度筛选**：按楼栋、年份、月份、状态（已售/未售/渠道/不可售）筛选
- **阅后即焚**：开启后关闭浏览器自动清空价格数据
- **打印 PDF**：一键打印销控表（含表头、蓝底表头、红底已售）
- **导出 Excel**：每栋楼支持导出 Excel 文件
- **深色/浅色主题**：支持亮色/暗色模式切换

## 使用说明

1. 首次使用点击「楼栋管理」配置楼栋框架（名称、单元数、楼层范围、房型）
2. 进入销控表后，点击「导入数据」导入成交台账
3. 支持手动编辑单个房源（点击单元格）
4. 筛选栏可按年份、月份、状态组合筛选

## 技术说明

- 纯前端实现，单文件 HTML，无需后端
- 数据存储在浏览器 localStorage
- 适配 Chrome/Edge/Firefox 现代浏览器
